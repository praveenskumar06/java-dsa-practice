# PROJECT MANDATE & WORKFLOW RULES

## PROJECT NAME
Praveen — Canada Job Search + Interview Prep + Finance

## PROJECT PURPOSE
A structured, persistent workspace containing all resources, plans, scripts, study material, interview preparation, and financial planning required for Praveen’s Canada job search and long-term career growth.

## CORE PRINCIPLES
1. Files must remain stable, organized, and never corrupted.
2. No duplication, no clutter, no overloading with unnecessary information.
3. All updates must be made to the same existing files inside `InterviewPrep/`.
4. Content must remain crisp, senior-level, and interview-ready.
5. The system must be reusable and expandable throughout the project.

## INTERVIEWPREP FOLDER STRUCTURE & FILES
The following 6 Markdown files inside `InterviewPrep/` must be reused and updated cleanly:
1. `InterviewPrep/SELF_INTRO_Praveen.md`
2. `InterviewPrep/INTERVIEW_CODING_QA_MASTER.md`
3. `InterviewPrep/SYSTEM_DESIGN_DAILY_NOTES.md`
4. `InterviewPrep/BEHAVIORAL_QA_MASTER.md`
5. `InterviewPrep/INTERVIEW_FILLER_SENTENCES.md`
6. `InterviewPrep/DAILY_PREP_TRACKER.md`

## WORKFLOW RULES FOR ANY AGENT
1. Never create new files unless explicitly instructed.
2. Always update the existing files inside `InterviewPrep/`.
3. Keep content crisp, structured, and senior-level.
4. When user says "Start Day X", add:
   - 5–7 coding questions in Option-C format
   - 1 system design concept
   - 1 behavioral answer (STAR format)
   - Daily tracker update
5. When user says "Give me more questions", provide a batch (5–7), not one-by-one.
6. When user says "Open <file>", display the exact file content.
7. When user says "Update <file>", append or modify content cleanly.
8. Never overload files with unnecessary theory or long paragraphs.
9. Maintain consistency across all files.

## USER GOALS
- Secure a Senior Java / Full Stack Developer role in Canada.
- Build strong DSA + system design fundamentals.
- Develop niche specialization in AI/RAG + Java.
- Maintain a clean, structured interview preparation system.
- Keep all files persistent and reusable throughout the project.

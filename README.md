# Java DSA Practice

This project is a simple Java and Data Structures practice workspace for beginners.
It is organized by topic so you can learn Java basics, OOP, and DSA step by step.

## Project Structure

- basics/ - beginner Java programs
- oops/ - classes and object examples
- dsa/arrays/ - array problems
- dsa/strings/ - string problems
- dsa/linkedlist/ - linked list problems
- dsa/stack/ - stack problems
- dsa/queue/ - queue problems
- dsa/tree/ - tree problems
- dsa/graph/ - graph problems
- dsa/dp/ - dynamic programming problems
- notes/ - short study notes

## How to Run Java Files in VS Code

1. Open the Java file you want to run.
2. Click the Run button above the main method.
3. If prompted, select Java as the language.
4. The output will appear in the Terminal panel.

You can also run from the terminal:

```bash
javac FileName.java
java FileName
```

## How to Practice DSA Daily

- Spend 30 to 45 minutes each day.
- Solve one topic at a time.
- Read the code carefully before changing it.
- Try to rewrite the same solution in your own words.
- Keep a small notebook for mistakes and patterns.

## How to Push This Project to GitHub

1. Open the project folder in VS Code.
2. Open the terminal and run:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

If you do not have a GitHub repo yet, create one first on GitHub and copy its URL.
